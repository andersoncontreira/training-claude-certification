# Documentation Rules

- All Markdown files in this project must be written in English.
- Every public class and public method must have a docstring.
- Docstring format: Google Style.
- When creating or updating an endpoint, update `docs/api/` accordingly.
- ADRs (Architecture Decision Records) go in `docs/project/adr/` using the
  template at `docs/project/adr/0000-template.md`.
- Do not duplicate documentation — link between files instead of copying content.
